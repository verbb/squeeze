<!-- feature-intro -->
Squeeze packages one or more Craft assets into a downloadable ZIP when a visitor asks for them. Build secure download experiences from the files already in Craft without preparing every archive in advance.
<!-- feature-intro-end -->

<!-- feature-section -->
## On-demand ZIP downloads

Pass selected Craft assets to Squeeze and generate an archive on demand. It works for a single file or a collection, making it suitable for resource packs, media kits, document bundles, and user-selected downloads.

<!-- feature-section-end -->

<!-- feature-section -->
## Secure download links

Generate signed URLs with an expiry so the archive route does not become a permanent public endpoint. Templates remain responsible for deciding which assets belong in the bundle and when a link should be offered.
<!-- feature-section-end -->
